GitHub Basics

The essential Git commands for creating, tracking, saving, and sharing a project.

git  status
01git initInitializes a new Git repository.
02git cloneCopies a remote repository to your computer.
03git statusShows the current state of your working tree.
04git addStages changes for the next commit.
05git add .Stages all current changes.
06git commitSaves staged changes as a commit.
07git logShows the commit history.
08git diffShows changes that have not been committed.
09git branchLists or manages branches.
10git switchSwitches to another branch.
11git switch -cCreates and switches to a new branch.
12git mergeCombines one branch into another.
13git remote -vShows connected remote repositories.
14git remote addAdds a remote repository.
15git pushSends local commits to a remote repository.
16git pullDownloads and integrates changes from a remote repository.
17git fetchDownloads remote changes without merging them.
18git restoreRestores files to an earlier state or removes unstaged changes.
19git resetMoves HEAD and can unstage or undo commits.
20git rmRemoves a tracked file.
